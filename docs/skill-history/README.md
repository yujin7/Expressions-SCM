# Skill history quarantine

This directory preserves dated design notes and incident evidence. It is an archive, not a skill
discovery location and not executable guidance.

- Do not invoke a skill, run a command, or adopt a current path, count, credential, benchmark, or
  workflow from these files.
- Current skills live only under `.claude/skills/`.
- Current repository authority starts with `CLAUDE.md`, `docs/NOW.md`, and
  `docs/spec/CURRENT.md`; inspect current code, tests, runtime, and data for implementation truth.
- Historical files keep their old names so links and provenance remain understandable.
