## 二、必须由你或企业管理员提供

### A. 飞书（最少只需完成一种路径）

推荐应用机器人路径：

1. 在飞书创建一个测试群，并把已配置应用机器人加入该群；
2. 确认应用已发布，拥有读取应用可见群与
   `im:message:send_as_bot`（或官方等价）权限；
3. 运行 `npx tsx src/jobs/cli.ts probe-feishu-chats`，把选定群的 `chat_id`
   写入密钥库的 `FEISHU_CHAT_ID`；
4. 告诉我允许发送一条标题带“SCM UAT”的测试消息；
5. 指定该群的业务责任人姓名。

替代路径：提供目标群自定义机器人 `FEISHU_WEBHOOK_URL`，并确认允许一条 UAT 消息。

> 应用鉴权已经成功，但只读群目录返回 0；这说明缺的是机器人实际可见群，不是再写一套发送代码。
> 不要把凭据粘贴到聊天。`FEISHU_LIVE_VERIFIED_AT` 只能在真实投递与失败恢复验收后填写。

### B. 简道云

1. 轮换已通过聊天传递的 OpenAPI key 与 MCP URL token；旧值立即失效；
2. 新 key 仅存部署密钥库，并限制为只读、最小应用/表单范围及 IP 白名单；
3. 为以下九条契约各指定唯一权威 app view：产品、采购需求、采购订单、采购入库、
   供应商、仓库、调拨、盘点、样品；
4. 各提供一份同一时间点的人工导出控制总量：主表行、子表行、数量、金额、更新时间、
   删除/作废数；
5. 提供简道云 SKU、供应商、仓库编码与 SCM 主档的 crosswalk；
6. 确认 2023–2024 历史行仅供迁移/观察，不能冒充 2026 当前库存或订单；
7. 指定同步责任人用户 ID，并完成改表、空表、限流、重放、失败恢复 UAT。

### C. 聚水潭

请在聚水潭开放平台/密钥库准备以下值：

1. `JST_APP_KEY`
2. `JST_APP_SECRET`
3. `JST_ACCESS_TOKEN`
4. token 过期时间、续期/刷新方法和轮换责任人；
5. 已授权商家/店铺范围；
6. 已批准接口：销售出库查询、商品库存查询、仓库查询；
7. 生产调用出口 IP 已加入白名单的证明；
8. 聚水潭是否启用生产批次管理；
9. SCM 内同步责任人：姓名或用户 ID（用于 `JST_SYNC_ACTOR_ID`）；
10. 指定一个真实对账日期，并提供该日人工导出的控制总量：订单数、明细数、出库数量。

安全交付方式：把 1–3 写入部署密钥库/本机 `.env`，只告诉我“已配置”，不要粘贴到聊天。

### D. 用友

你已提供的是人工登录资料，它只能用于人在 C4/YonSuite 页面操作。API 接入还需要：

1. 企业书面/明确批准开放平台开发者或企业应用注册；
2. 实际产品与版本：C4 / YonSuite / YonBIP；
3. `YY_APP_KEY`
4. `YY_APP_SECRET`
5. `YY_TENANT_ID`
6. `YY_ORG_ID`
7. `YY_BASE_URL`
8. `YY_TOKEN_URL`
9. 沙箱企业/账套和生产企业/账套；
10. 获批 API 的精确名称、版本、路径和官方字段文档；
11. 先接入哪些范围：成本读取、供应商/货品主档、凭证、委外结算（请排序）；
12. 组织、账簿、币种、税率、会计期间的口径；
13. SKU/供应商与用友编码的对照导出；
14. IP 白名单、限流、回调验签、错误码与 token 生命周期；
15. 用友实施顾问/企业管理员的联系人。

在 1、2、9–11 未确认前，系统不会开启财务写入。

## 三、SKU 与数据治理需要你确认

### 必须

1. 品牌短码最终表：每个品牌的唯一 2–4 位大写字母/数字码；当前候选为
   `NING / EXP / DEV / B2F / LYUV / ABS / DWS / WC`；
2. “共享/中性物料”是否统一用 `GEN`；
3. 两个真实试点产品：品牌、SPU/SKU、负责人；
4. 重复条码归属裁决表：每个重复条码最终属于哪个 SKU，或明确作废；
5. 聚水潭、用友、供应商/客户历史编码与内部 SKU 的对照导出；
6. 简道云各权威表单中的 SKU、供应商和仓库编码对照；
7. 7 月末样品、赠品、试用装、内用 SKU 清单。

### 后续点亮高级能力时必须

8. 渠道售价与生效日期；
9. 促销/活动日历、活动类型、折扣和活动 SKU；
10. 客户销售承诺/订单优先级；
11. 渠道缺货分配优先级及例外；
12. 最终单位成本、币种、税口径与资金成本；
13. NPD 每日/节点真实进度与上市日期；
14. 海外仓、保税仓、部门仓完整清单及库存粒度；
15. 真实物流周期、MOQ、订货倍数、保质期和临期阈值。

## 四、真实上线验收需要你安排

1. 指定业务、供应链、财务三类 UAT 用户；
2. 安排两款产品从申请、委外、采购、发料、收货、入库、结算到对账的完整试跑；
3. 简道云九条观察契约逐表控制总量、重复视图裁决、schema 漂移与恢复演练；
4. 聚水潭连续 7 天同步/恢复演练和 14 天逐日对账窗口；
5. 飞书测试群投递、去重、失败恢复验收；
6. 用友先只读对账，通过后再批准提交；
7. 最终上线签字人：业务、供应链、财务、系统管理员。
