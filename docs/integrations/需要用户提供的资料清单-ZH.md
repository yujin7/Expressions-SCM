# 需要用户提供的资料清单（精确版）

更新日期：2026-07-30
原则：密码、secret、token 不再发到聊天，不写文档或 Git；只放部署密钥库或本机未跟踪 `.env`。

## 一、当前凭据结论

| 系统 | 已有 | 仍缺 | 结论 |
|---|---|---|---|
| 飞书 | 本机已有 `FEISHU_APP_ID`、`FEISHU_APP_SECRET` | `FEISHU_CHAT_ID`（或 webhook 二选一）、机器人入群/权限、真实测试 | 部分配置，尚不能投递 |
| 聚水潭 | 官方文档链接 | `app_key`、`app_secret`、`access_token`、IP/接口授权、责任人 | 没有机器凭据 |
| 用友 | C4 人工登录入口/账号 | 企业 OpenAPI 应用、client 凭据、租户/组织、接口与沙箱 | 人工登录不等于 API 凭据 |

## 二、必须由你或企业管理员提供

### A. 飞书（最少只需完成一种路径）

推荐应用机器人路径：

1. 目标测试群的 `FEISHU_CHAT_ID`；
2. 确认机器人已加入该群并允许发言；
3. 确认应用已发布，拥有 `im:message:send_as_bot` 或等价发送权限；
4. 告诉我允许发送一条标题带“SCM UAT”的测试消息；
5. 指定该群的业务责任人姓名。

替代路径：提供目标群自定义机器人 `FEISHU_WEBHOOK_URL`，并确认允许一条 UAT 消息。

> 已有 app ID/secret 不需要再次发送；只需在安全配置中保留。

### B. 聚水潭

请在聚水潭开放平台/密钥库准备以下值：

1. `JST_APP_KEY`
2. `JST_APP_SECRET`
3. `JST_ACCESS_TOKEN`
4. token 过期时间、续期/刷新方法和轮换责任人；
5. 已授权商家/店铺范围；
6. 已批准接口：销售出库查询、商品库存查询、仓库查询；
7. 生产调用出口 IP 已加入白名单的证明；
8. 聚水潭是否启用生产批次管理；
9. SCM 内同步责任人：姓名或用户 ID（用于 `JST_SYNC_ACTOR_ID`）；
10. 指定一个真实对账日期，并提供该日人工导出的控制总量：订单数、明细数、出库数量。

安全交付方式：把 1–3 写入部署密钥库/本机 `.env`，只告诉我“已配置”，不要粘贴到聊天。

### C. 用友

你已提供的是人工登录资料，它只能用于人在 C4/YonSuite 页面操作。API 接入还需要：

1. 企业书面/明确批准开放平台开发者或企业应用注册；
2. 实际产品与版本：C4 / YonSuite / YonBIP；
3. `YY_CLIENT_ID`
4. `YY_CLIENT_SECRET`
5. `YY_TENANT_ID`
6. `YY_ORG_ID`
7. `YY_BASE_URL`
8. `YY_TOKEN_URL`
9. 沙箱企业/账套和生产企业/账套；
10. 获批 API 的精确名称、版本、路径和官方字段文档；
11. 先接入哪些范围：成本读取、供应商/货品主档、凭证、委外结算（请排序）；
12. 组织、账簿、币种、税率、会计期间的口径；
13. SKU/供应商与用友编码的对照导出；
14. IP 白名单、限流、回调验签、错误码与 token 生命周期；
15. 用友实施顾问/企业管理员的联系人。

在 1、2、9–11 未确认前，系统不会开启财务写入。

## 三、SKU 与数据治理需要你确认

### 必须

1. 品牌短码最终表：每个品牌的唯一 2–4 位大写字母/数字码；当前候选为
   `NING / EXP / DEV / B2F / LYUV / ABS / DWS / WC`；
2. “共享/中性物料”是否统一用 `GEN`；
3. 两个真实试点产品：品牌、SPU/SKU、负责人；
4. 重复条码归属裁决表：每个重复条码最终属于哪个 SKU，或明确作废；
5. 聚水潭、用友、供应商/客户历史编码与内部 SKU 的对照导出；
6. 7 月末样品、赠品、试用装、内用 SKU 清单。

### 后续点亮高级能力时必须

7. 渠道售价与生效日期；
8. 促销/活动日历、活动类型、折扣和活动 SKU；
9. 客户销售承诺/订单优先级；
10. 渠道缺货分配优先级及例外；
11. 最终单位成本、币种、税口径与资金成本；
12. NPD 每日/节点真实进度与上市日期；
13. 海外仓、保税仓、部门仓完整清单及库存粒度；
14. 真实物流周期、MOQ、订货倍数、保质期和临期阈值。

## 四、真实上线验收需要你安排

1. 指定业务、供应链、财务三类 UAT 用户；
2. 安排两款产品从申请、委外、采购、发料、收货、入库、结算到对账的完整试跑；
3. 聚水潭连续 7 天同步/恢复演练和 14 天逐日对账窗口；
4. 飞书测试群投递、去重、失败恢复验收；
5. 用友先只读对账，通过后再批准提交；
6. 最终上线签字人：业务、供应链、财务、系统管理员。

## 五、系统可自行完成，不需要你提供

- S1 自动取号、校验码、并发防重；
- GTIN Mod-10 校验和包装层级管理；
- 外部编码/历史编码登记、搜索、导入解析；
- 重复归属拦截、审计留痕、停用不删除历史；
- 代码测试、迁移、构建、GitHub PR 与受保护分支合并；
- 凭据 readiness 检查（只报告缺失字段，不输出 secret）。
