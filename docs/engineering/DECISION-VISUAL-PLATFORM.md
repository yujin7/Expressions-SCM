# 决策可视化平台

## 目标

把“194 个图表想法”建设成一套可持续扩展的决策系统，而不是 194 个互不一致的页面。
每张图必须帮助一个角色回答一个问题，并能追溯口径、来源、时点、覆盖与限制。

## 唯一图卡契约

新图表统一使用 `DecisionVisual`，必须提供：

1. 决策问题；
2. 指标 ID（指标公式唯一登记在 `components/metrics.ts`）；
3. 分析粒度和单位；
4. 数据来源、信任层级和截至时点；
5. 覆盖率或明确说明为何无法计算；
6. 当前筛选；
7. 一句可被屏幕阅读器读取的结论；
8. 关键限制；
9. loading / empty / error / insufficient / ready 五态之一；
10. 图形之外的数据表、分享链接和全屏分析；小结果集可直接 CSV 导出。

语义颜色统一来自 `components/decision-visuals.ts`。颜色不得成为唯一信号；阈值、标签、
文字摘要和数据表必须同时存在。

## 已落地的决策闭环

| 入口 | 已回答的问题 | 事实层 |
| --- | --- | --- |
| 经营驾驶舱 | 销量趋势、品牌/渠道集中、重点 SKU、仓库分布、覆盖和效期风险 | 销售月事实、库存账、快照、批次 |
| 库存分析 | 哪些 SKU 处于缺货/积压异常象限，货压了多久，周转是否健康 | 库存账、快照、销售月事实 |
| 需求达成 | 需求缺口集中在哪些渠道 | 月度需求与达成登记 |
| 总库存核对 | 有多少 SKU 可比，可比部分有多少一致 | 外部总库存、库存账、最新快照 |
| 全链漏斗 | 需求、计划、下单、到货、动销的量级落差出现在哪里 | 月度需求、BH/WO/PO/SH、销售月事实 |
| 销售桥 | 品牌、渠道或 SKU 如何解释两个窗口之间的销量变化 | 销售月事实 |
| 预测准确率 | 哪些 SKU 存在高误差或系统性高估/低估 | 预测版本、销售月事实 |
| 供应商评分 | 交付与检验表现集中在哪些供应商 | PO 承诺、收货与检验事实 |
| 补货推演 | 当前供需管道何时跌破安全库存，参数变化如何影响结果 | 库存账、销售月事实、供给管道 |
| 委外在制 | 待收量集中在哪些加工厂，哪些 JG 已逾期 | JG、正常收货行 |
| 新品项目 | 哪些项目与节点已经落后计划 | NPD 项目、实例化节点任务 |
| 决策工作室 | 哪些品牌/渠道/SKU 贡献 80%，趋势是否异常，当前数据还能支持哪些结论 | 销售月事实、JST 日销量受控暂存、能力证据门禁 |

所有筛选和视图状态进入 URL；刷新、分享、前进后退不会丢失现场。
全尺寸 Recharts 图形由架构测试强制使用统一图卡；紧凑型 sparkline 必须提供可读文本摘要。

决策工作室已把原始图表组合中的可行部分收口为同一分析现场：帕累托/80-20、成员点击
联动、同组中位基准、环比、按证据解锁的同比和 SPC、自助月度透视、JST 日销量热力以及
不调用 LLM 的事实型月度回顾。透视与图形先在服务端全量聚合，客户端只负责切换和下钻。
同一回顾每个数据月只进入通知 outbox 一次；未配置飞书时留在站内，配置后自动出圈。

## 数据闸门

以下图表不能用假数提前“做出来”，只允许显示 `insufficient` 和解锁条件：

- 日销、促销提升、断货损失：需要日粒度销量、促销和可售状态；
- 收入、毛利、营运资金、现金转换：需要销售价、成本、应收应付事实；
- 同比、季节性、稳定控制限：需要至少 12–24 个月一致历史；
- 供应商交期分布：需要 PO 承诺日到真实收货日的足够闭环样本；
- 批次谱系和 FEFO 绩效：需要所有收货/发料/退料/成品入库稳定过账批次；
- NPD 学习曲线：需要多项目真实节点历史，而非单个模拟项目。

上述闸门不是“未开发页面”。决策工作室会展示解锁条件、当前覆盖和责任动作；只有来源契约、
质量校验、新鲜度与失败补偿一起成立，分析状态才能从 `insufficient` 变为 `ready`。

`主数据健康度 → 决策能力解锁` 将这些前提做成可分享的证据清单：已证明、待解锁、责任团队和
下一动作同屏显示。完成一个前提必须同时落地来源契约、质量校验、新鲜度和失败补偿，不能只改
卡片状态。

## 迁移顺序

1. 新页面从统一图卡开始，不再产生第二套图表协议；
2. 聚合必须由全量服务端事实计算，禁止用当前分页数据冒充全量；
3. 每次只完成一个“发现异常 → 下钻 → 责任人行动”的闭环；
4. 新数据源接入后再解锁闸门中的图表；
5. 注释、管理故事和跨期比较需要持久化模型与权限审计，进入独立写路径设计，
   不以浏览器本地备注冒充组织事实。
