# 驾驶舱读取、权限与钻取复核

2026-09-08；候选工程记录，不是上线或业务UAT证明。对应总监CK四屏、预警、调拨和待办需求；不替代101条逐项验收。

## 用户闭环与修复

计划员/仓管进入四屏 → 看来源、时点与未知 → 查看例外 → 到同一筛选/期间/具体单据。沿用现有读模型、授权、URL列表状态和useDocumentRead，不增加BI平台或改业务计算规则。

- 主概览与趋势分别挂载读取；主概览慢/失败不挡趋势，切视图不重挂趋势。取消模块全局趋势缓存，离开后不把前一会话结果当新事实。
- 两类读取均有15秒超时、取消、迟到回复保护与显式重试；刷新先撤下旧事实。两者独立恢复，不声称同一原子快照；卡片业务截止和读数生成时间分开。
- 覆盖计数按真实status=alert/watch钻取，断货仍按primary=out_of_stock；总数包含C层，链接也包含C层。非法status在读模型载入/刷新前400拒绝。
- 本月完成数是当月创建队列中的已完成量，改标“本月创建·已完成”，链接带同一创建月份到完成率统计，不跳所有历史已完成事项。
- 调拨异常按docId直达库存单据抽屉，不把单号作为模糊搜索交给列表。
- 仓管响应的salesAmount容器曾被通用金额脱敏整键删掉，UI读取state时崩溃。容器改为monthlySalesBlock，内部真实salesAmount仍受原权限剥离；补脱敏后的行为检查及仓管五视图浏览器检查。所有源码消费者同步修改，API和前端须同版本部署，不保留敏感同名别名。
- 视图导航改普通可换行链接，保留URL、键盘与当前项。原AntD窄屏溢出Tab在390px实测无法可靠选中渠道视图。没有用隐藏溢出掩盖问题。
- 历史月份最新优先、每页6个月，保留全部月份分页。缺数卡片改紧凑文字说明，保留来源和入口，取消重复大幅空态插图；仅限本页块壳，不做全站CSS覆盖。
- 时间格式走既有零依赖上海业务日权威；无时区的模糊时间和非法日期不猜测。技能引用现有客户端边界白名单，去掉重复维护的过时单项名单，不新增权限例外。

- 9文件70项专项通过（生命周期、实际路由过滤与权限、服务装配、金额脱敏、日期格式、深链、客户端边界、技能契约）；三套类型与改动lint通过。最后紧凑空态增量仍由准确候选完整门复验。

- 调拨QA库原来只有期初单；首次新增钻取断言失败，未放宽成任意单据。仅经现有API在隔离库创建一张QA调拨草稿；不审批、不移动库存。卡片异常行注入该真实QA单据ID，目标详情走真实API。
- 真实读取覆盖样本多为ok；watch/alert非零分布由规则夹具验证，浏览器对比完整返回与筛选返回。不能把合成异常或0条watch当作真实业务异常识别验收。
