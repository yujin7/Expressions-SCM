- **Cockpit does not use the metrics registry.** Import `metric()`/`metricTooltip()` from `src/components/metrics.ts` into `cockpit-client.tsx` and delete the duplicated caliber prose in `cockpit.ts` `note:` fields. **Effort S**, and it removes an active drift source (the `METRICS` caveat and the cockpit note already disagree in places).

Worth confirming with the data owner before any PDD figure reaches the director.
