# 搜索与导航体验复核

日期：2026-09-07。基线dbf5b9e；本批次候选，不是实际3100部署或全站/UAT完成证明。

## 真实任务与修复

计划员从任意页面找到页面或实体，确认匹配身份，进入相应事实，并在失败时知道如何恢复。

- CommandPalette与GlobalSearch共用useEntitySearch：300ms防抖、取消过期请求、10秒超时、显式失败/重试；
  旧查询在新响应前即撤下，关闭/卸载取消；不缓存跨用户结果。同名项用查询/位置/目标身份区分。
- 页面目标与实体响应分开派生；数据响应不再清空页面导航。注册表95条全部参与角色过滤后的发现，
  比原55条多40条；其中含query深链，不等于新增40个页面。不更改菜单结构或服务端权限。
- 桌面有明确快捷入口，手机有点按入口；不要求手机用户使用键盘快捷键。
- Modal打开动画结束后聚焦输入；rc-select在弹出列表时会吞掉Escape冒泡，改为捕获本面板关闭键，
  忽略输入法组合事件。取消后回到触发控件，导航成功则不抢新页面焦点。
- 状态说明放在输入框上方，避免被选项浮层盖住。错误为中文安全类别；不原样复述未知异常。
  下拉长名允许换行，类别词不拆字；仅搜索浮层加作用域，不全局改变所有Select。
- 真浏览器发现供应商URL带q但API取q空串。服务器页面读取异步searchParams，传入供应商客户端和
  CrudTable初始搜索；按导航查询重挂载表格，输入框与首次API一致。其他CRUD消费者缺省行为保持不变。

## 失败到通过的证据

1. 原9项行为反例7失败；修复后扩展到26项，包含同名、过期/乱序、关闭、失败、超时、重试、
   不安全目标、权限、输入过短、焦点回调与未知报错。该hook/callback夹具不是DOM/React调度证明。
2. 点按入口与打开后聚焦新增2项先失败；实现后通过。供应商深链真浏览器先捕获API q为空，修后为编码。
3. 真实浏览器首轮Escape回焦点失败；查明rc-select停止冒泡，再修捕获关闭和显式焦点归还。
4. 初版搜索CSS被AntD默认规则覆盖，computed whiteSpace仍nowrap；提高本浮层选择器优先级后为normal，
   验证内容clientWidth=scrollWidth=276。不是靠隐藏溢出消除问题。
5. 新供应商测试最初readonly tuple类型错误；改为显式输入类型后三套类型通过，未放松业务断言。

最终定向7文件70项通过；三套类型、改动文件eslint零警告。尚待本候选精确提交的完整发布门。
