## 对历史总账需要校正的四处表述

1. **不是整个简道云连接器停摆。** 09-05 仍有天猫、拼多多流成功；受阻的是一条全量镜像流。旧编排遇失败退出，确实可能阻断后续流和尾部刷新，但不能外推为全部流失效。
2. **尾部缺失不是删除证明。** 保存的序列按来源记录 ID 规范化，不是 API 分页顺序。缺失形状只是线索；墓碑须业务回源确认，签认也不能绕过截断与完整性检查。
3. **投递成功不能排除产品摩擦。** 待办集中分配、来源入口不精确、操作含义混淆和加载竞态均可能影响使用。未读、未处理的数据本身不能证明员工不愿使用。
4. **不是任意关闭一次就开始学习。** 当前结局回验限定已关闭的库存覆盖告警，至少等待 3 天且具有可用库存证据。完成待办不等于关闭告警；关闭其他类别也不等于获得断货学习样本。
