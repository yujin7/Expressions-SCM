# 编码标准裁决简报（用实跑数据算过的）

日期：2026-08-07
用途：把「编码路线三选一」从一个听起来很大的架构决定，变成一个可以当场拍板的选择。
数据来源：生产容器 PostgreSQL 实测查询（非推断、非文档转述）。

---

## 0. 先更正我自己的一句话

2026-08-04 那份审计里，我把现状描述成
**「两套并行 + 单向兼容 + 语义完全丢失」**，并说这是「最坏的一种状态」。

**这个描述不准确。** 实测：

```
skus 表里 S1 编码的行数                 0
sku_identifiers 里 S1 值的行数           0
```

**S1 标准从来没有产生过一个真实编码**——一行都没有。它只存在于代码和文档里。

所以现状不是「双轨」，而是：**一条在跑的轨（公司 N001 体系），和一条从未通车的轨。**
这让三选一里的两个选项基本失去意义。

---

## 1. 实跑数据：公司标准的真实符合度

### 成品（1,026 个）

| 形态 | 数量 | 占比 |
|---|---:|---:|
| 三位序号 `N001-000`（公布标准原型） | 519 | 50.6% |
| 两位序号 `A01-001`（同结构、序号两位） | 196 | 19.1% |
| 小样 `X` 形（各式） | 227 | 22.1% |
| 真正无规律 | **84** | **8.2%** |

**91.8% 的成品编码已经在遵循公布标准的某种形态。**
所谓「不合规」的大头是**两位序号 vs 三位序号**这一个差异，不是混乱。

### 物料（4,350 个）

| 形态 | 数量 | 占比 |
|---|---:|---:|
| 带四位分类码（`E001-0401` 等） | 3,885 | 89.3% |
| 独立前缀族（`TYCL01/ZYTY0x/P01/F01/FY/ZCLY`） | 128 | 2.9% |
| 其它 | 347 | 8.0% |

**92.0% 的物料编码符合公布标准。**

### 名称

| 指标 | 数量 |
|---|---:|
| 名称已是 `(品牌)…(规格)` 形 | 675 |
| `short_name`（系统命名方案要用的简称）有值 | **0** |
| `version` 有值 | **0** |
| `product_type` 有值 | **0** |

系统那套命名方案（品牌+渠道+**简称**+版本+规格）依赖的三个字段，**全库皆空**。
也就是说它同样从未真正启用过。

---

## 2. 三个选项，按实跑数据重新估价

### (a) 全面切 S1，旧码只读保留
- 要把 5,376 个 SKU 从一个 **91.8% / 92.0% 已在遵循**的标准，
  迁到一个 **0 行采用**的标准；
- 公司现行标准是**智能码**（能读出品牌、是否小样、物料分类），S1 是**哑码**；
  切过去等于主动放弃编码里的语义，而业务的日常识别正依赖它；
- 4,474 行包材参考、BOM、历史单据全部要跟着重挂。
- **代价极大，且没有任何既有 S1 数据可以保护。**

### (b) 系统实现公司 N001 体系，S1 停用
- **迁移成本≈0**：没有 S1 数据需要保留或转换；
- 工程量集中在「让系统读得懂已经存在的编码」：
  编码解析/校验、小样 X 段、多规格 -1/-X1、版本类型后缀、物料分类码字典
  （分类码字典**本轮已经补完并上线**，32 个编码族全覆盖）；
- 需要处理的历史清理面很小：成品 84 个 + 物料 347 个，合计 **431 个**（占全库 8.0%）；
- 顺带要裁决一件小事：**两位序号（196 个）是否并入标准**，还是逐步规整为三位。

### (c) 双轨并行 + 映射层
- 映射层是为「两套都有数据」准备的。**这里一套是空的**，
  建映射层等于给一个不存在的问题写代码。

---

## 3. 结论与建议

> **建议选 (b)。** 不是因为它最省事，而是因为**它已经是事实**——
> 91.8% 的成品和 92.0% 的物料本来就在用这套标准，而 S1 有 0 行采用。
> 选 (b) 是承认现状；选 (a) 是推翻一个正在正常运转的体系去迁就一个没人用的体系。

选 (b) 之后能立刻解锁的（这些现在都卡着）：
- 批量采用标准名 / BI 用简称 —— 会改为按公司名称规则做，`short_name` 这条死路可以放弃；
- 编码格式校验：录错 `N1-000`、`N001-00` 当场拦下（现在一律放行）；
- 正装↔小样自动配对、多规格与版本类型结构化承载。

### 需要你确认的只有三件事

1. **选 (b) 吗？**（若是，S1 转为仅保留代码、不再生成）
2. **两位序号 `A01-001` 是并入标准，还是逐步规整成三位？**（涉及 196 个）
3. **431 个无规律编码**：是安排人清理，还是先挂「历史遗留」标记不阻断业务？

三件事都答完，编码与命名这条线就能一次做通。
