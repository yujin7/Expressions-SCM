# 供应商字段保留与账期有效性

2026-09-08。D64纠错、G03必要前置；不等于账期谈判闭环完成。实际3100、真实数据、D69–D71、原工作区173路径未改。

## 问题与范围

独立研究发现两个现有测试未覆盖的反例：通用供应商编辑只提交账期时清空产能、反向亦然；未来生效月结在生效前计入当前达标。继续追踪发现部门目标可以保留旧自动达标值，供应商缓存的全表max(updatedAt)也可能漏掉同毫秒或非最大时间戳记录的变化。

不另建审批平台或财务事实。沿用采购/管理员登记权限、原45–60天目标和审计路径；不冒充历史协议管理、谈判案件或应付账款。

## 实施契约

- 通用编辑先验单字段，锁定当前供应商后按字段存在性合并，再校验最终账期/产能组。未提交组及组内字段保留；显式清空、非月结清天数、非法月结与缺产能单位分别受测。
- 专用账期/产能写入亦锁定当前记录，审计before与序列化后的真实状态一致；业务写入及审计同事务。日历非法日期在SQL前拒绝。
- 上海业务日区分已生效、待生效、待核对。未来协议可登记，不提前计达标；缺协议类型/生效日或月结天数不猜值。最近登记条款没有历史有效版本时显示未知，不推断旧协议。
- 候选率仍为已确认达标候选÷候选总数，不是谈判关案率。采购额占比只按当前有效条款分类；非零采购额对应未知条款时占比弃权，已分类月结采购额是小计，不是应付余额。
- 缓存v2绑定上海日与供应商相关字段指纹；替代单一最大更新时间，避免同时间戳更新漏失效。PO/JS等既有源绑定未被本批重设计，不宣称全部缓存失效路径已穷尽。
- 目标读取只显示经源绑定核对的账期自动值，不在GET改库。自动刷新在事务内锁目标并复查人工值；来源不可用时清除旧自动值并审计，不继续显示旧达标。此刷新失效处理覆盖所有既有自动指标，人工证据值保留。
- 目标actualValue/actualSource同时为空或同时有值，遵守既有数据库配对约束；不靠放松约束修测试。
- 账期页沿用useDocumentRead的取消、15秒超时、撤下旧值及重试；CSV增加上海截至日与条款状态。无金额角色的有往来筛选用独立存在性字段，不因金额脱敏清空供应商。
- 驾驶舱优先展示结构化账期类型/天数；旧原文不能把当前75天显示成60天，仅有原文时明示未结构化。原文存储未改，生效状态仍独立展示。
- 桌面宽表保留内部横滚；窄屏用完整单列证据卡。KPI手机两列、同排等高；安全提示常显，长口径复用CaliberNote。弹窗独立于表格列，缩放不丢输入。
