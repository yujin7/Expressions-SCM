# 让同事（含外地/外网）访问系统 — 选型与步骤

日期：2026-08-07

## 先说清楚现状

| 地址 | 同网段 Mac/iPhone | 同网段 Windows/安卓 | 外网 |
|---|---|---|---|
| `http://exp-scm.local:3100` | ✓ | ⚠️ 多半不解析 | ✗ **永远不可能** |
| `http://<本机IP>:3100` | ✓ | ✓ | ✗ |

两个硬约束，不是配置能绕开的：

1. **`.local` 按定义只在同一网段内有效**（mDNS/RFC 6762，靠组播、不经路由）。
   它走不出这栋楼，这是该后缀的定义，不是没配好。
2. **本机局域网 IP 每天在变**——2026-08-05~07 实测漂了八次
   （`3.154 → 10.86 → 3.154 → 1.253 → 30.138 → 31.49 → 10.44 → 3.154`）。
   任何写死 IP 的链接都会在你换一次网络后失效。

**结论：要一个「发给所有人、长期有效」的链接，必须换方案。**

---

## 三个方案

### A. Cloudflare 隧道 — 同事什么都不用装

```
https://exp-scm.你的域名.com
```

- **任何人、任何设备、任何网络，打开就能用**；真 HTTPS，不再明文传密码
- 地址与本机 IP 完全无关，换网络/重启都不受影响
- 不需要公网 IP、不需要在路由器开洞
- **成本**：域名约 ¥60–100/年；Cloudflare 免费计划即可
- **你要做的**：把域名 DNS 托管到 Cloudflare，然后跑一条命令
- **注意**：这是公网地址。建议叠加 Cloudflare Access（只放行指定邮箱），
  在系统登录页之前再加一道闸

```bash
npm run access:tunnel -- exp-scm.你的域名.com
```

### B. Tailscale — 不上公网，最安全

```
http://100.x.x.x:3100    （或 MagicDNS 机器名）
```

- 地址固定、随处可用；**流量完全不经公网**，由 WireGuard 加密
- **成本**：0（免费计划够小团队）
- **你要做的**：打开 Tailscale.app 登录，把同事邀请进同一个 tailnet
- **代价**：每位同事要装一个客户端并登录

```bash
npm run access:tailscale
```

### C. 搬到云服务器 — 长期真正的答案

隧道解决的是「地址」，解决不了**「这台机器是笔记本」**：
合盖、休眠、你带电脑出门、切 VPN —— 每一样都会让全组断线，跟地址无关。

只要这套系统成为团队日常依赖，最终都得挪到一台常开的机器上：

- 一台 2 核 4G 云主机（阿里云/腾讯云轻量）约 ¥60–100/月
- 固定公网 IP + 域名 + TLS，7×24 在线
- 现有 `docker-compose.prod.yml` 可直接用，迁移主要是搬数据卷
- 需要迁：PostgreSQL 数据、`uploads/` 附件、`.env.prod` 密钥（**密钥须重新生成**）

## 建议

| 你的情况 | 选 |
|---|---|
| 想马上有个链接发群里，同事不折腾 | **A** |
| 不想有公网入口，同事愿意装客户端 | **B** |
| 这套系统要长期给全组用 | **C**（可先用 A/B 过渡） |

**最快路径：先 B（今天就能好，0 成本），确认大家用得顺之后再上 C。**

## 两条命令都已备好

脚本都是幂等的，会自己校验前置条件、切好 `AUTH_URL`、重启应用、
并轮询 `/api/health` 直到 200 才报成功，最后打印可直接发群的链接。

它们**只在你完成登录后才会真正开通** —— 没有你的账号，脚本会停在第一步并告诉你要做什么。

### 为什么每次都要动 AUTH_URL

`AUTH_URL` 必须与同事**实际输入的地址**完全一致，否则登录后回跳会指向一个不存在的地方
（表现就是「页面能开但登不进去」）。

实测过一个坑：**留空不行** —— standalone 容器里 credentials 回调会解析成
服务端自身绑定地址 `http://0.0.0.0:3000`，即便 `trustHost: true` 也一样。
所以脚本一律显式写死。

### HSTS

已改为受 `PUBLIC_HTTPS` 门控：只有走 HTTPS（方案 A）时才开。
明文 HTTP 下开 HSTS 会把自己锁在门外——浏览器记住后强制跳 https，
而局域网 `http://<ip>:3100` 没有证书，直接变成打不开。
