## 0. 现状基线

- 自建 Next.js 15 + PGlite/Postgres 系统已替代 Excel 主流程：主数据（5,376 SKU）、委外单据链（BH/WO/PO/JG + 物料收发 + 结算）、库存过账（decimal 纪律、红字冲销、审计全覆盖）、9 类业务文件导入管线、16 迁移、430+ 测试、21 项冒烟。
- 已建智能层：库存未来曲线、控制塔、ABC/XYZ、SKU 360、闭环追踪、Holt 预测、What-if 沙盘、守护式自动补货、供应商确认门户（token/TTL/单次/逐行交期）、通知发件箱（飞书 webhook 就绪）、毛利 v1（手工成本）、主数据健康度、每日摘要。
- 三层口径纪律（记账/快照/参考）与人工闸（R13）为全系统底线，本 PRD 所有条目不得破坏。

## 1. 愿景与设计原则

1. **从记录系统到决策系统**：每个数字可解释、每个建议可追溯、每个决定有结局记录。
2. **诚实优先**：无数据不臆造（毛利无售价则留白）；参考层永不入账；口径永远标注。
3. **人工闸不动摇**：自动化产草稿，审批永远是人。
4. **学习闭环**：参数由数据建议、由人采纳；预测被复盘；覆盖被归因。
5. **一处定义，处处一致**：指标、术语、权限、告警——单一注册表驱动所有表面。

## 3. 成功度量

- 资金：过期库存件数（现 3,224）清零后不复发；调拨替代采购件数；库存周转次数
- 计划质量：预测 MAPE、建议采纳率（到货口径）、人工覆盖后被证实率
- 流程：BH→入库中位周期、审批中位时长、月结耗时
- 数据健康：完全健康 SKU 占比（现 281/5376）、文件新鲜度达标周数
- 采用度：周活跃角色数、⌘K/保存视图使用率、飞书通知点击率
