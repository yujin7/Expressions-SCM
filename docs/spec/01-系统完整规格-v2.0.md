## 1. 架构与技术栈

### 1.1 总体架构
```
浏览器(内网/VPN) ── Next.js 应用(SSR+API) ── PostgreSQL 16
                          │                      │
                     pg_boss 后台任务       仅追加账本(流水/审计, 按月分区)
                          │                      │
              导入中心(Excel/CSV) ←─ RPA产物(1.1) 附件卷(照片/导入文件, 纳入备份)
              聚水潭导出(P0手动/P1 API)
              飞书 OAuth(需出网连通) / P2 飞书消息+审批
```

### 1.2 技术选型
| 层 | 选型 | 备注 |

| 前端+服务端 | Next.js 15 + TypeScript | 单仓单进程 |

## 4. 单据状态机与过账表

```
草稿 ─提交→ 待审批 ─通过→ 已审批 ─[PO/JG:确认(代录)]→ 执行中 ─完成→ 已完成
  │            │驳回→草稿              │                    │
  └─作废       └─撤回→草稿             └─短关(留原因)→ 已关闭 ─重开(管理员)→ 执行中
```
- **纠错=红字冲销**（负数流水引用原单，审批留痕）；**取消反审批机制**。
- **作废级联矩阵**：WO 作废→未执行的 PO/JG 自动作废；已部分执行→WO 短关 + 已发料走 TL 退回 + 已收货保留。PO/JG 短关：冻结剩余数量，允许 JS 按短关口径结算。
- 部分执行：SH/FL 分次；父单显示进度；超收容差默认 0%（参数）。

**过账表（唯一权威，`posting/registry.ts` 实现，防旁路测试由此生成）**
| 触发 | 流水 |
|---|---|
| 采购收货检验后入库 | 仓库 +合格数（让步另入+打标） |
| 采购退货 CT 审批 | 仓库 −；PO 已收数回冲 |
| 委外发料 FL 审批 | 自有仓 −，委外仓 + |
| 委外退料 TL 审批(检验后) | 委外仓 −，自有仓 + |
| 委外收货检验后入库 | 成品仓 +(合格+让步打标)；委外仓 − 净标准用量×(合格+让步+备品) |
| 备品入库 | 成品仓 +（子类型"委外入-备品"，零成本）+ 对冲池台账 |
| JS 审批 → **损耗核销** | 委外仓 − 实际损耗（带内不计价核销；超额部分对应扣款）；**核销后该 JG 委外仓余额必须=0**（残留强制先走 TL 或差异说明） |
| 销售出库(导入/手工)审批 | 自有仓 − |
| 调拨审批 | 转出仓 −，转入仓 +；**转入=快照仓时 → 调拨在途仓 +**，到仓确认后"调拨核销" − |
| 期初/盘点调整审批 | ± |
| 红字冲销审批 | 原单流水取负 |
| 快照导入(1.1) | 覆写 stock_snapshot（不触 ledger） |

## 5. 核心业务规则（R1–R12，`rules/` 纯函数+单测）

- **R1 价格异动**：见《00》A5 终版（基础单位未税比价 / 首购免检 / 基准绑定 PO 终审 / PC 生效范围）。
- **R2 损耗容差**：唯一来源=sys_param 品类允许损耗率（包材5%，其余 D5 补齐）；结算不受计划损耗影响。⚠ 计划侧 lossRatePct 已被《04》§2 改判为行级双损耗（来料/生产），毛需求公式见 04 §2。
- **R3 SPU/SKU 归集**：SKU 必挂唯一 SPU；报表默认 SPU 口径下钻 SKU。
- **R4 库存账务**：见《00》A6 终版（快照独立表 / 委外仓可负 / 调拨在途 / 在途=PO 实物行未收量）。
- **R5 委外结算（逐物料）**：
  ```
  有效完工数 Q = 合格 + 让步接收 + 备品
  对每一物料 i（js_line）:
    净标准用量ᵢ = BOM单位用量ᵢ × Q
    允许损耗ᵢ   = 净标准用量ᵢ × 品类允许损耗率ᵢ
    实际损耗ᵢ   = 累计发料ᵢ − 累计退料ᵢ(TL) − 净标准用量ᵢ
    超额损耗ᵢ   = max(0, 实际损耗ᵢ − 允许损耗ᵢ)        ← 逐物料, 禁止轧差
    扣款ᵢ       = 超额损耗ᵢ × 当月加权平均价ᵢ（含税口径与应付一致）
  应付加工费 = Σ按收货时点分段(合格数 × 当时JG加工费现价) + 让步数 × 让步单价(D6,默认全价,财务审批)
  备品不计加工费；结算金额 = 应付加工费 − Σ扣款ᵢ ± 手工调整(审批留痕)
  ```
- **R6 供应商评分**（P1）：⚠〔过期：本权重提案已被 D7 代决（质量40/交付40/价格20、季度）取代，以 CURRENT.md 为准〕准交40/质量40/配合20 为**提案**（D7 待采购+品控确认权重与频率）；红线冻结新 PO。
- **R7 对冲池**：备品/损耗/补送入池（计价=当月加权平均），季度盘点后一张冲销调整单。
- **R8 编码**：doc_counter 行锁取号 + UNIQUE(doc_no)。⚠ SKU 主码规则已被《04》§9 改判为待 D10（方向=现行商家编码）——"品类2位+5位"勿再使用；SPU=`P`+5位（doc_counter 取号，见 04 §4.1）。
- **R9 脱敏**：敏感字段清单=成本价/采购价/合同价/**加工费单价/结算金额/扣款单价**；运营与仓管不可见；PMC/采购/财务可见（●）；**唯一收口=每实体 dto.ts**（RSC/路由/导出全部经此，lint 强制）；报表与看板继承同一规则。
- **R10 并发**：乐观锁+幂等（同幂等键重试返回缓存结果，**优先于版本冲突**）；过账/审批表 UNIQUE 硬约束；余额更新按键排序。
- **R11 净需求建议**：建议量 = 毛需求 − 可用库存 − 在途，按 MOQ/订货倍数向上取整；三数并示由采购确认。
- **R12 更正**：任何已审批库存单据可开红字（引用原单、负数流水、审批留痕）；红字后可重开正确单据。

## 7. 集成规格

### 7.1 导入中心（模板定版 9 个）
主数据 6（SPU/SKU、分类、供应商、仓库、BOM、价格表）+ 期初库存 + 聚水潭销售出库日汇总 + （1.1）快照仓 T-1（库存/出库/在途三段，支撑纪要"出库排名"统计）。
流程：模板下载→上传→逐行校验→错误报告→预览→确认。幂等：快照/汇总按(模板+业务日期)覆盖；主数据按编码 upsert。审计：1 行/任务。

### 7.2 聚水潭
P0 人工导出→导入；**仓库映射规则**：自有仓发货行→生成销售出库单；快照仓发货行→不入账本，仅参与(1.1)快照差异对账。对账口径=自有仓发货订单。P1 API（限流 5/s、100/min，排队器）。

### 7.3 飞书：MVP 仅 OAuth（W0 验证出网）；P2 审批+推送。
### 7.4 财务（P1）：凭证导出文件对接用友；**ERP 主数据同步**（客户/供应商/货品，PRD P1 原文）纳入 P1 范围，方向与频率届时定。
### 7.5 PO 对外单据：1.x 打印模板+固定合同条款（PDF，少量变量）；P1 第三方电子签（对应纪要"电子章/盖章付款全流程"）。
### 7.6 开放 API（P1）：REST+OpenAPI，token 鉴权，只读优先。
