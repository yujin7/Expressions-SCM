# SKU 编码标准 S1

生效日期：2026-07-30
适用范围：未来新建/替代 SKU；历史 SKU 不改码
系统入口：主数据 → SKU 货品 → 编码标准

## 1. 一句话规则

新建 SKU 时将“编码”留空，系统保存时自动生成：

`S1-来源-类型-六位全局流水-两位校验码`

例如：`S1-EXP-F-000123-K7`

## 2. 每段是什么意思

| 段 | 示例 | 含义 |
|---|---|---|
| 方案版本 | `S1` | 第一版 SKU 编码规则；未来规则变化必须升版本 |
| 来源 | `EXP` | 品牌起源短码；共享/中性物料用 `GEN` |
| 类型 | `F` | SKU 类型 |
| 全局流水 | `000123` | 企业唯一顺序号，由系统并发安全取号 |
| 校验码 | `K7` | 发现常见误录，不代表审批或权限 |

类型码：

| 类型码 | 类型 | 中文 |
|---|---|---|
| `F` | finished | 成品 |
| `H` | semi | 半成品 |
| `R` | raw | 原料 |
| `P` | packaging | 包材 |
| `V` | service | 服务 |

## 3. 为什么不把更多信息写进编码

渠道、供应商、工厂、规格、颜色、售价、生命周期、当前品牌归属、BOM 父产品和法规市场均可能
变化。它们已经有主档字段或关系表，重复写进永久编码会导致：

- 同一物料因共用或换供应商出现多个编码；
- 渠道、版本或规格调整时被迫换码；
- 历史订单、库存、BOM 和外部系统对照断裂；
- 人工从编码猜业务含义，与系统事实不一致。

所以 S1 只保留稳定身份所需的最小信息。

## 4. 新旧编码如何共存

1. 现有 `E054-000`、`N02-003-a`、`DEV025-0201-1` 等编码永久保留。
2. 不批量重编号，不修改历史单据、库存、BOM、附件或台账关联。
3. 外部系统码、条码和旧码继续通过别名注册表解析。
4. Excel/staging 导入继续接受真实历史和外部编码。
5. 页面新建时推荐留空自动生成；只有确有其码的历史/外部货品才手工输入。
6. 手工输入以 `S1-` 开头时，系统会检查格式、校验码、品牌来源和 SKU 类型。
7. 已创建 SKU 的主码不可修改；替代关系通过新 SKU、旧码别名和生命周期表达。

## 5. 操作示例

### 新成品

- 品牌：EXPRESSIONS（短码 `EXP`）
- 类型：成品
- 编码：留空
- 保存结果示例：`S1-EXP-F-000123-K7`

### 共享包材

- 品牌：留空或按主档治理
- 类型：包材
- 编码：留空
- 保存结果示例：`S1-GEN-P-000124-2M`

### 已有外部编码

- 外部系统真实编码：`E054-000`
- 编码：填写 `E054-000`
- 系统原样保留，不转换为 S1。

## 6. 管理纪律

- 不用 `MAX+1` 取号；系统使用 `doc_counters` 原子取号。
- 流水允许跳号。跳号不代表丢数据，通常来自事务回滚或碰撞避让。
- 校验码只防误录，不能替代唯一约束、角色权限、审批、审计和外部对账。
- 来源段代表创建时的稳定起源，不因后续品牌归属调整而改码。
- 发现重复主档时只进入人工裁决，不按名称或编码相似度自动合并。
