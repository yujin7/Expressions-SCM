## 给业务同事的词汇表

- **SPU**（你们说的"款式/产品族"）：同一产品的不同规格/版本归为一个 SPU 看报表。例：N006 系列 3 个规格 = 3 个 SKU，1 个 SPU。`-a`(升级版)/`-X`(小规格) 归属同一 SPU（**D17 已代决 2026-07-24**）。
- **快照仓**：系统只存"每日照片"（盘点/RPA 数据）、不记流水账的仓——保税仓、云仓、平台仓（E 仓=电商仓）。自有仓才逐笔记账。
- **红字冲销**：错账不改不删，开一张负数单据冲掉，两笔都留痕（≠作废：作废是单据从未生效）。
- **让步接收**：检验不合格但决定收下入库的货，单独打标、单独定结算价。
- **抽盘**：即原 PRD 的"永续盘点"——不停业，按循环计划抽点部分货位。
- **lifecycle 四态**：在售/试销/停售/淘汰（替代"启用/停用"开关）；试销=新品观察期，报表打标。
