## 1. MVP 目标（一句话）

**用系统完整跑通一条真实委外链路——备货申请→委外工单→采购/加工通知→发料→收货检验→入库→结算——库存账实时可信、错账可红字纠正、结算可逐物料对得清，并与聚水潭日数据对上。**

## 3. 核心链路（含审计修正点）

```
[运营]BH ─PMC审批→ [PMC]WO(选生效BOM→wo_line快照: 毛需求/可用/在途/建议量[R11])
  WO审批(PMC审批人≠制单人) → 生成 PO(仅原料/包材行) + JG(携带加工费现价)
  PO提交 → R1(基础单位未税比价) ─异动→ PC(生效范围必填) ─通过→ PO审批(采购审批人)
  PO/JG [供应商确认-内部代录] → 执行中
  [仓管]FL(按wo_line预填;超发管理员批) → 自有仓−/委外仓+
  （加工中…剩料/换料 → TL退料: 委外仓−/自有仓+）
  [仓管]SH(挂JG,分次;行类型: 正常|返工重交[冲抵不合格,不占累计]|备品[不占JG数量])
      → QC(合格/不合格/让步) → 入库: 成品仓+(合格+让步*标记); 委外仓−净标准用量×(合格+让步+备品)
      不合格三路径: 退厂返工 / 让步(单价D6审批) / 报废(红字)
  收货关闭或短关 → [PMC]JS: js_line 逐物料(R5) + 让步/备品处理
      → 财务审批 → 损耗核销流水, 该JG委外仓余额强制=0
  错账任意环节 → 红字冲销单(引用原单,审批) → 重开正确单
```

**关键校验**：SH 累计分母=JG数量−已判不合格+容差；FL 欠发/超发展示；JS 1:1 于 JG；库存变动只能来自《01》§4 过账表（防旁路测试自动生成）。

## 6. 验收标准（DoD——全部可测量）

1. **真单**：**5 角色（含运营发起 BH）**完成 ≥1 真实委外订单全链路；且演练单覆盖异常路径各≥1 次：驳回重提、分次收货、返工重交、TL 退料、红字冲销、让步接收。
2. **对账**：自有仓发货口径，按自然日、SKU 级，|系统出库−聚水潭出库|÷聚水潭出库 ≤1%，**连续 14 天逐日全过**（W7–W8 窗口），由 reconcile-jst 报告自动出数，财务签字确认。
3. **规则单测**：R1/R2/R5/R8/R10/R11/R12 分支覆盖 100%，边界清单显式列出（0 损耗、恰 5%、跨段改价、退料后结算、备品+让步混合、首购、单位换算比价）。
4. **不可旁路**：由过账表 registry **机械生成**断言——遍历全部路由，任何写库存路径必须命中过账表；审批后不可编辑；审批/过账 UNIQUE 约束生效（并发双审批测试）。
5. **性能（staging）**：100 万行流水造数下，余额/流水/在制看板查询 **P95≤1s**；100 并发混合脚本 30 分钟无死锁、无 5xx；5 万行导出异步生成 ≤5s。
6. **脱敏**：**运营+仓管**账号全路由自动扫描（含导出文件与 RSC 载荷）：R9 黑名单字段零出现。
7. **上线门（W8 末）**：S1/S2 缺陷=0；并行运行未触发中止阈值（S1 缺陷或连续 2 日差异>3%）；**财务+PMC+运营三方签字**（签字人 D9 确认）。
