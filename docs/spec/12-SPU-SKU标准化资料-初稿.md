# 12 · SPU/SKU 关联配置标准化资料（初稿·待供应链+财务审定）

> 出处：0724 会议「需明确 SPU 定义、SKU 与 SPU 的关联关系配置逻辑，由供应链联合财务输出标准化资料」。
> 本稿由系统现行规则反写（04 §4.1 / D3 / D17 / D31），两部门只需**审定或改判**，不必从零起草。
> 系统现状：348 SPU / 5,376 SKU 已按本规则落库；124 个歧义簇打 needsReview 标待复核（复核清单）。

## 1. 定义（一句话版）

- **SKU（货品）**：可独立备货、独立记账的最小单位——一个商家编码=一个 SKU（D10：沿用现行商家编码为主码）。
- **SPU（产品）**：同一款产品的不同规格/版本/生产模式的归集单位——报表看盘、库存归集按 SPU（服装行业「同款不同码」类比，会议 0723 认可）。

## 2. SKU→SPU 归组规则（现行系统执行口径）

| 规则 | 内容 | 例 |
|---|---|---|
| R-A 双证归组 | 族前缀相同 **且** 归一化品名相同 → 同 SPU（两证齐全自动归组；任一不符→人工裁决队列，绝不硬归） | N006-001 / N006-002 / N006-003 → SPU「N006 系列」 |
| R-B 变体后缀 | `-a`(升级版)、`-X`(小规格) 与原款**同 SPU**（D17 已裁） | E01-001 与 E01-001-a 同款 |
| R-C 中英同名 | 中英文名指向同一产品的不同版本 → 同 SPU（会议 0723「同一中英文名归集」） | — |
| R-D 生产模式 | 同款不同生产模式（自产/委外/保税加工）**不拆 SPU**，模式记在 SKU 属性 | — |
| R-E 人工兜底 | 规则不能双证判定的 100% 进人工裁决（放行工作台），系统不猜 | 124 簇现挂 needsReview |

## 3. 编码规则（D31，2026-07-30 已闭环）

- **存量**：全部旧编码原样保留，永不改码（避免历史资料改造）。
- **增量**：未来新建/替代 SKU 推荐留空，由服务端按
  `S1-来源-类型-六位全局流水-两位校验码` 原子取号。
- **边界**：历史/外部真实编码仍可显式录入；以 `S1-` 开头的手工码必须通过完整校验。
- **说明**：详见 [`19-SKU编码标准-S1.md`](19-SKU编码标准-S1.md)。

## 4. 财务侧口径（需财务确认三点）

1. 成本归集层级：按 SKU 记、按 SPU 汇（与 D2 季度盘点均摊法衔接）——确认☐
2. SPU 口径报表（库存/销量归集）作为管理口径，法定账仍按 SKU——确认☐
3. 变体（-a/-X）并入原款 SPU 后，历史成本/售价差异在 SPU 汇总中直加呈现（不加权）——确认☐
