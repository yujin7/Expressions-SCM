# 07 · UAT 场景矩阵与并行运行手册

> 服务 02 §7 W6（UAT）与 W7+（并行运行）；03 §2-30 与 D9 的落地物。
> 前置：D15 时间线已裁决；DW2 主数据放行完成（751 SKU 入正式库）；staging 环境就绪。

## 1. UAT 入场 / 出场标准

**入场**：全量测试套件绿（≥240）；期初迁移演练已在 staging 完成并由仓管签字；5 角色账号与权限就位；培训（每角色 1 场）完成。
**出场**：下表 41 个场景全部通过或有书面豁免；S1/S2 缺陷=0；S3 有修复排期；三方（财务+PMC+运营）签署 UAT 通过单。
**缺陷分级**：S1=数据错账/权限穿透/系统不可用；S2=主流程受阻无绕行；S3=有绕行的功能缺陷；S4=体验/文案。修复后必跑全量回归（vitest + 链路 e2e）。

## 3. 并行运行手册（W7+，D9 材料）

**原则**：系统为准、旧流程（用友+Excel）兜底记录不停。
**每日核对清单（15 分钟/角色）**：
- 仓管：系统库存余额 vs Excel 台账（自有仓逐 SKU 差异清单，容差 0）
- 财务：当日对账差异页 = 0 或全解释；期初/结算审批无积压
- PMC：在制看板 vs 在途 Excel 跟进表（新单部分）
- 采购：PO 状态 vs 用友（外部单号对照表）
**中止阈值（触发即冻结系统录入并升级项目会）**：S1 缺陷 1 个；或自有仓对账差异 >3% 连续 2 日；或任一角色核对清单连续 3 日无法完成。
**回退程序**：冻结系统写入 → 以系统日报（导出）将增量补录回旧流程 → 复盘 → 择期重启并行。旧流程在并行期为"暂缓"非"停止"。
**上线门签字**：财务 ____ PMC ____ 运营 ____ 日期 ____（DoD-2 十四日对账报告与 UAT 通过单附后）。
